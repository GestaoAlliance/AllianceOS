# AllianceOS visual direction

The attached Cilo references are the canonical visual direction for AllianceOS:
- black / white / cool gray;
- high-contrast typography;
- thin borders and generous internal spacing;
- compact navigation rail;
- context panels that read like customer-context cards;
- task execution surfaces separated from configuration;
- dark mode as a true inversion of the same system;
- liquid glass limited to floating/contextual surfaces.

Avoid beige/cream backgrounds, oversized rounded containers touching screen edges, and nested cards without clear hierarchy.
